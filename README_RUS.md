# VR Mirror by U2VR (`obs-vr-mirror-by-u2vr`)

[English version](README.md) | **Русская версия**

Нативный C++/DirectX 11 плагин для **OBS Studio (30.x / 31.x / 32.x)**, созданный специально для захвата **SteamVR (включая Quest 3 через SteamLink)** с **аппаратной 3D-стабилизацией по датчикам шлема** и **бесшовным совмещением двух глаз** (ведущий правый глаз с прицелом + расширение обзора левым глазом до 16:9) и другое.

---

## Ключевые особенности

1. **Прямой GPU-захват обоих глаз из SteamVR (`IVRCompositor::GetMirrorTextureD3D11`)**
   * В отличие от обычного захвата окна зеркала SteamVR (где до 40% вертикального обзора уже обрезано под 16:9), плагин забирает **полные квадратные (1:1) текстуры левого и правого глаза** напрямую из видеопамяти.
   * Благодаря этому стабилизация по вертикали (тангаж / Pitch) и по крену (Roll) использует **реально отрендеренные игрой пиксели сверху и снизу** — без черных полос и без потери четкости.

2. **Точная синхронизация с позой кадра (`Compositor_FrameTiming::m_HmdPose`)**
   * Плагин берёт из SteamVR именно ту матрицу вращения датчиков Meta Quest 3, с которой игра отрендерила текущий кадр ($\mathbf{R}_{\text{reproj}} = \mathbf{R}_{\text{raw}}^T \mathbf{R}_{\text{smooth}}$), что исключает фазовое «желе» при быстрых движениях.

3. **Режим двух глаз как в SteamVR («Правый ведущий + Левый слева») и другие режимы**
   * Правый глаз занимает основную и центральную часть кадра (~82–85%), поэтому коллиматорные и оптические прицелы при стрельбе правым глазом отображаются **строго в том месте, куда вы целитесь**, без двоения и параллакса.
   * Левый глаз достраивает периферию слева через мягкий градиентный шов (`smoothstep`), формируя широкую картинку 16:9.

4. **Двухрежимный адаптивный фильтр + Удержание горизонта (Roll Lock)**
   * Гасит физиологический микротремор головы и мелкую вибрацию легкого шлема Quest 3.
   * При резких осознанных разворотах на 90°–180° плавно ускоряется (ограничитель максимального угла), чтобы камера не «отставала» от игрока.
   * Отдельный регулятор **Стабилизация крена / Горизонт (Roll Lock)** убирает покачивание горизонта влево-вправо (главную причину укачивания зрителей на стриме).

## Структура проекта

* [`CMakeLists.txt`](CMakeLists.txt) — конфигурация сборки CMake.
* [`src/plugin-main.cpp`](src/plugin-main.cpp) — точка входа плагина OBS, динамическая загрузка OpenVR и свойства источника.
* [`src/stabilizer_math.h`](src/stabilizer_math.h) — математика кватернионов, адаптивный SLERP-фильтр и стабилизация горизонта (Roll Lock).
* [`src/d3d11_stabilizer.h`](src/d3d11_stabilizer.h) — D3D11 рендерер и HLSL-шейдер 3D-репроекции и сшивки двух глаз.

* [`Install-Plugin.ps1`](Install-Plugin.ps1) — скрипт установки в папки плагинов OBS Studio.

## Установка

### Вариант 1. Готовый релиз (Рекомендуется)

1. Скачайте архив релиза (`obs-vr-mirror-by-u2vr-v*.zip`) со страницы [Releases](https://github.com/alextrof94/SteamVR-capture-plugin-for-OBS/releases).
2. Закройте OBS Studio, если он запущен.
3. Распакуйте архив в директорию установки OBS Studio (например, `C:\Program Files\obs-studio` или `D:\Steam\steamapps\common\OBS Studio`).
   
   Файлы плагина должны оказаться в подпапке `obs-plugins\64bit`:
   * `<OBS_DIR>\obs-plugins\64bit\obs-vr-mirror-by-u2vr.dll`
   * `<OBS_DIR>\obs-plugins\64bit\openvr_api.dll`
4. Запустите OBS Studio.

### Вариант 2. Сборка из исходников

1. **Требования:**
   * Windows 10/11 (64-bit)
   * Visual Studio 2022 с компонентом «Разработка классических приложений на C++» (MSVC v143, x64)
   * CMake 3.20+
2. **Сборка:**
   Запустите PowerShell-скрипт сборки в корне репозитория:
   ```powershell
   .\Build-Plugin.ps1
   ```
   Скомпилированные файлы появятся в каталоге `dist\obs-vr-mirror-by-u2vr\bin\64bit\`.
3. **Установка скриптом:**
   ```powershell
   .\Install-Plugin.ps1 -RestartOBS
   ```
   Скрипт автоматически найдет установленные директории OBS Studio, при необходимости закроет процесс OBS, скопирует библиотеки и перезапустит программу.

## Использование в OBS Studio

1. В OBS Studio в списке источников нужной сцены нажмите **«+»**.
2. Выберите источник **«VR Mirror by U2VR»**.
3. Рекомендуемые настройки (выставлены по умолчанию):
   * **Режим захвата глаз:** `Правый ведущий + Левый слева (Как в SteamVR, прицел правым)`
   * **Сила стабилизации (Pitch / Yaw):** `65 %`
   * **Стабилизация крена / Горизонт (Roll Lock):** `75 %`
   * **Макс. угол компенсации:** `8.5 °`
   * **Запас кадрирования / Зум:** `6.0 %`
   * **Расширение вторым глазом / Сдвиг сшивки:** `18.0 %`
   * **Мягкость шва между глазами:** `8.0 %`
   * **Смещение камеры вверх/вниз:** если в шутерах при прицеливании камера смотрит слишком низко в пол, поставьте `+5 % .. +10 %`, чтобы поднять ракурс за счёт запаса квадратной текстуры глаза.
